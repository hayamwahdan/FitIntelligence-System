# Body Performance Analytics & Intelligent Classification System

## 🎓 Project Context
This project was developed as a final course project for the **Introduction to AI & ML** course during the **"Digital Pioneers Initiative - مبادرة الرواد الرقميون"**, under the supervision of **Dr. Mohamed Kamel El Haddad**.

## 📋 Project Overview
This system implements a complete machine learning lifecycle to analyze human physical fitness. Using a dataset of over 13,000 records, we built models to:
1.  **Classify** individuals into fitness categories (A, B, C, or D) based on physical metrics.
2.  **Predict** explosive power (broad jump distance) using regression techniques.

## 🚀 Key Results
*   **Top Classification Model:** Neural Network (Accuracy: **76.33%**)
*   **Top Regression Model:** Decision Tree (R²: **0.9684**, RMSE: **6.98 cm**)
*   **Key Insight:** Flexibility (sit and bend) and core endurance (sit-ups) were identified as the strongest predictors of overall fitness levels.
